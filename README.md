# CEH 312-50 Study Notes

Personal study notes for the **Certified Ethical Hacker (CEH)** exam, covering all 20 domains of
the standard CEH v12 blueprint. Each module follows the same structure — introduction, objectives,
techniques, tools, hands-on labs, countermeasures, and reporting — so they're quick to scan the
night before a review session.

## Source note
Modules 2–13 are based on my own course material. Module 1 and modules 14–20 (Web Applications,
SQL Injection, Wireless, Mobile, IoT, Cloud, Cryptography) were written to fill in the standard
CEH v12 blueprint where my original notes didn't cover the topic in detail yet — treat those as a
solid starting outline to expand with your own course/lab material over time.

## Companion practice tool
These notes pair with a separate offline **practice app** (question bank + timed mock exam +
learning path) built from the same modules — not included in this repo, kept as a local tool.

## How to use this repo
- Read module notes top to bottom before drilling practice questions on that topic.
- The **Reporting** section in each module doubles as a mini checklist for what a real penetration
  test report should capture for that phase.
- Every module ends with a disclaimer — none of this is a license to test systems you don't own or
  don't have explicit written authorization to test.

## ⚠️ Legal & Ethical Use
All content here is for **educational purposes and authorized penetration testing only**.
Unauthorized access to computer systems, networks, or data is illegal under laws such as the
Computer Fraud and Abuse Act (CFAA) and equivalent legislation worldwide. Always obtain explicit,
written authorization (Rules of Engagement) before testing any system you do not personally own.
